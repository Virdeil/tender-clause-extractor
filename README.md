# 招标文件条款抽取器

从政府采购磋商文件中自动抽取「无效条款」（如 26.3.x 系列），输出结构化的 Excel 汇总表。

## 项目背景

投标时最贵的错误不是报价高，是**废标**——一条没注意到的无效条款，会让整份标书作废。
这类条款散落在上百页文件里，人工通读需要 2–3 小时，且必然遗漏。

本项目把这件事自动化：读入 txt → 调用大模型抽取 → 输出 Excel。

## 功能

- 批量处理一个文件夹下的所有 `.txt` 文件
- **长文本自动分段**（每段 4000 字），避免超出模型输入长度被静默截断
- 多段结果按条款号**合并去重**
- 单文件失败自动重试（只对网络类错误重试，配置类错误立即停止）
- 输出 `.xlsx`，含「文件名 / 条款号 / 原文」三列
- 打印 token 用量，成本可见

## 环境准备

```bash
pip install requests openpyxl
```

设置 API Key（不写进代码）：

```powershell
[Environment]::SetEnvironmentVariable("SF_API_KEY", "sk-你的key", "User")
```

**设置后必须关掉终端重新打开**，环境变量才会生效。

## 使用

把待处理的 `.txt` 放进 `批量测试/` 目录，然后：

```bash
python 02_批量处理.py
```

输出示例：

```
[1/3] A_26.3节选.txt（2072 字）
    第 1/1 段（2072 字）→ 11 条
    → 去重后 11 条，耗时 16.8s，token 输入 3120 / 输出 480
```
仓库内附 sample.txt（来源：中国政府采购网公开文件），可直接用于跑通 01 脚本。
## 实现要点

| 问题 | 处理方式 |
|---|---|
| 长文件返回 0 条 | 按 4000 字分段，逐段抽取后合并 |
| 分段边界切断条款 | 优先在换行处断开 |
| 同一条款被多段抽到 | 按 `clause_no` 去重，保留首次出现 |
| 模型套 ```` ```json ```` 代码块 | 截取第一个 `[` 到最后一个 `]` 再解析 |
| 网络抖动 | 重试 3 次；但 401/402/403/404 不重试 |
| API Key 泄露 | 从环境变量读取，仓库内不含明文 |

## 实测数据

| 输入 | 模型 | 抽出条数 |
|---|---|---|
| 2,072 字 | Qwen2.5-7B | 9 / 11 |
| 2,072 字 | DeepSeek-V3 | **11 / 11** |

同提示词、同输入，仅更换模型，召回率从 82% 提升到 100%。

## 已知限制

- 分段边界若正好切开一条条款，该条可能残缺
- 目前只抽取固定编号规则（26.3.x），换成其他编号需改 `PROMPT`
- 未做并发，文件多时较慢
